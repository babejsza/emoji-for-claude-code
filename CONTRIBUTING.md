# Contributing

## Ground rules

- **No runtime dependencies, no network access, no telemetry.** The only devDependency is
  `@vscode/test-electron`, pinned to an exact version.
- **The .vsix is a whitelist.** Only the files listed in `.vscodeignore` are shipped.
- **Keep the legacy names.** The project used to be called `claude-better-chat`. Installs patched by 0.1.x
  carry its markers (`/* claude-better-chat:begin */` and `/* claude-better-chat:end */`), the backup suffix
  `.claude-better-chat.orig` and the localStorage key `claude-better-chat.emoji.recent`. Renaming any of them
  would leave those installs impossible to clean up or would lose users' history. `npm test` pins them.
- **Touch files only by explicit path.** Claude Code directories are identified by their `package.json`, never by a
  glob or name prefix, and temp files are removed by the exact path that created them.
- **Style:** 2 spaces, no semicolons, single quotes.

## Layout

| Path | What it is |
| --- | --- |
| `src/emoji-autocomplete.js` | The script appended to Claude Code's webview (DOM only, self-contained) |
| `src/emoji-data.json` | Emoji list and safe emoticons, generated by `tools/build-data.mjs` |
| `lib/patcher.js` | Apply / remove / status logic shared by everything below |
| `extension.js` | VS Code extension: consent, re-apply after Claude Code updates, commands |
| `uninstall.js` | `vscode:uninstall` hook that removes the patch |
| `bin/patch.mjs` | Command-line alternative to the extension |
| `tools/` | Emoji data builder, asset renderer and the shared headless Chrome driver (`cdp.mjs`) |
| `test/` | Unit tests, the headless Chrome test and the VS Code integration test |
| `images/` | Icon, publisher logo, screenshots and demo GIF, all generated by `tools/render-assets.mjs` |
| `README.md`, `CHANGELOG.md` | Marketplace page and release notes, both shipped in the .vsix |

## Prerequisites

- Node.js 22 or newer
- Google Chrome for `npm run test:e2e` and `tools/render-assets.mjs` (set `CHROME=<path>` if it isn't found)
- ffmpeg for the demo GIF
- Internet access for `npm run test:vscode` (downloads VS Code and the Claude Code extension) and for
  `npm run package` (fetches `@vscode/vsce` with npx)

## Tests

```sh
npm test               # patcher, CLI, uninstall hook, legacy installs, consent flow, emoji and emoticon data
                       # (EFCC_REAL_EXT=<claude ext dir> also runs them on a real Claude Code bundle)
npm run test:e2e       # typing, suggestions, keys, emoticons and undo in headless Chrome
npm run test:vscode    # real, isolated VS Code + the real Claude Code extension
```

Run `npm run test:vscode` after every Claude Code release. The test "this Claude Code build still has
the message box we look for" is the first to fail when Anthropic changes the chat input.

## Without the extension

```sh
node bin/patch.mjs           # apply to every installed Claude Code (VS Code, Insiders, Cursor, Windsurf)
node bin/patch.mjs status
node bin/patch.mjs remove
node bin/patch.mjs --help
```

## Emoji data

`src/emoji-data.json` is built from `emoji.json` of
[iamcal/emoji-data](https://github.com/iamcal/emoji-data) (MIT), currently at commit
`5cbb9b2a95fea05967f9b345cf56df4cbd0aebb8` (2026-03-15):

```sh
curl -sSfL -o /tmp/emoji.json https://raw.githubusercontent.com/iamcal/emoji-data/5cbb9b2a95fea05967f9b345cf56df4cbd0aebb8/emoji.json
node tools/build-data.mjs /tmp/emoji.json
```

The emoticons come from the same file, limited to the safe list in `tools/build-data.mjs`. To update, put the
commit you want into the URL and rebuild, then update the commit above and the emoji count in `README.md` and
`CHANGELOG.md` (the build prints it). Keep the iamcal notice in `LICENSE`.

## Release

1. Bump `version` in `package.json`, then run `npm install --package-lock-only` so `package-lock.json` matches.
2. Add the changes to `CHANGELOG.md`.
3. Run all three test suites. If anything visible changed, run `node tools/render-assets.mjs`.
4. Commit and push to GitHub first. The Marketplace page loads its images and the LICENSE link from the repository.
5. `npm run package` builds `emoji-for-claude-code-<version>.vsix`. Rebuild after the last edit to `README.md` or
   `CHANGELOG.md`, since both are packed into it.
6. Upload it in the [Marketplace publisher portal](https://marketplace.visualstudio.com/manage/publishers/babejsza)
   (three-dot menu, then Update) and attach it to a GitHub release tagged `v<version>`.
